Important: clicking .ics may not auto-import

Browsers and Google Calendar often do not import a calendar file from a simple click. Download the file first, then follow the steps below for your device.

iPhone / iPad (Apple Calendar)

  1. Tap Download calendar (.ics) above.
  2. Open the Files app → Downloads → tap instagram-post-reminders.ics.
  3. Tap Add All when prompted to add 17 events to Calendar.

Android (Google Calendar)

  1. Download the .ics file on your phone.
  2. Open Google Calendar → menu ☰ → Settings.
  3. Tap Import (or use calendar.google.com on desktop → Settings → Import & export).
  4. Select the downloaded instagram-post-reminders.ics file.

Desktop (Google Calendar)

  1. Go to calendar.google.com.
  2. Settings ⚙️ → Import & export → Import.
  3. Choose the downloaded instagram-post-reminders.ics file.
  4. Select your calendar → Import. You should see 17 events.
